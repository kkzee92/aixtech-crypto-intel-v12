# AGENTS.md

Rules for AI coding agents in this repository.

- Paper only. Do not add live order routing, withdrawal calls, or trade API keys.
- No personal data, wallet addresses, or secrets in fixtures, docs, or commits.
- Fixtures must be labelled SYNTHETIC and generated by scripts if present.
- Do not weaken risk caps, the kill switch, VaR gates, or the coverage floor to make a change pass.
- Tests must not call the network. Inject fetchers.
- Commit trailers: `AI-Assisted: yes` and `Human-Review: pending`.
- Do not remove the stress overlay, class cost model, multi-TF checks, trade-credential refusal, or expanded redaction.
